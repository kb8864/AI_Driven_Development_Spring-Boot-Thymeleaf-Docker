## 1. 検証の準備

### 1-1. 環境の確認

| No. | 確認内容 | 確認方法 |
| --- | --- | --- |
| P-1 | MySQL 9 が起動している | `mysql -u suser -pspass -e "SELECT 1"` が成功する |
| P-2 | `shop` データベースが存在する | `mysql -u suser -pspass -e "SHOW DATABASES"` に `shop` がある |
| P-3 | `item` テーブルに初期データ5件がある | 下記 1-2 のリセット手順を実行 |
| P-4 | ビルドが通る | `./mvnw clean compile` が `BUILD SUCCESS` |

### 1-2. データの初期化（各テストの前に実行）

テストでデータを変更するため、テストグループごとに以下でデータを初期状態（5件）へ戻す。

```bash
mysql -u root -p < SpringBoot用/20DB/31DML.sql
```

※ 31DML.sql は先頭で `DELETE FROM item` を実行してから5件を INSERT するため、これ1本で初期化できる。

### 1-3. アプリケーションの起動

```bash
cd shop01
./mvnw spring-boot:run
```

- 起動ログに `Tomcat started on port 8080` が出ることを確認する。
- ブラウザで `http://localhost:8080/items` を開く。

### 1-4. データ確認用 SQL

検証中、DB の実データを確認する際に使用する。

```sql
USE shop;
SELECT * FROM item ORDER BY id;
SELECT COUNT(*) FROM item;
```
